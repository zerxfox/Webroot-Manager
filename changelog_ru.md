v1.0.0

Основные функции:
- Начальная инициализация: Базовая структура и функционал модуля.
- Бургер-меню: Удобная навигация для управления настройками.
- Темы: Поддержка нескольких визуальных стилей интерфейса.
- Смена тем: Возможность переключаться между доступными темами в реальном времени.
- Смена иконок модулей: Динамическая проверка наличия иконки в папке модуля с использованием альтернативного пути, если файл отсутствует.
- Запоминание выбора темы: Выбранная тема сохраняется и применяется при последующих запусках.

Новые возможности для модулей:
- Динамическая генерация списка модулей: Генерация HTML-файла с картами для каждого модуля.
- Поддержка кастомных путей к иконкам модулей: Проверка наличия `module_icon.png` в папке модуля и использование стандартной иконки, если файл отсутствует.
- Интеграция с nginx: Автоматическое создание конфигурации для каждого модуля с доступом через веб-интерфейс.

v2.0.0

🔌 Эмуляция KSU WebUI API

- В HTML-страницы модулей, открываемые через Webroot Manager, теперь на лету инжектится JS-шим `window.ksu`, который эмулирует API KernelSU WebUI: `ksu.exec()`, `ksu.toast()`, `ksu.fullScreen()`, `ksu.moduleInfo()`.
- Добавлен серверный эндпоинт `POST /api/exec` (`Lua` + `ngx.pipe`), который выполняет shell-команду и возвращает `stdout`/`stderr`/код возврата в JSON.
- Доступ к `/api/exec` защищён одноразовым токеном (`X-Auth`), который генерируется при каждом запуске (`TOKEN=$(tr -dc 'A-Za-z0-9' </dev/urandom | head -c 32)`) и прокидывается в `<meta name="webroot-token">`.
- Благодаря этому модули, писавшиеся под встроенный WebUI KernelSU, теперь могут выполнять команды и показывать тосты прямо внутри Webroot Manager, без доработки под него отдельно.

🖼️ Модули теперь открываются во встроенном фрейме, а не редиректом

- Клик по карточке модуля больше не уводит на отдельную страницу, а открывает `iframe` во всплывающем оверлее (`module-frame-overlay`).
- Добавлена перетаскиваемая кнопка закрытия фрейма (drag & drop, поддержка `pointerdown`/`move`/`up`, с порогом в 6px, чтобы отличать клик от перетаскивания).
- Анимация фона страницы теперь ставится на паузу, пока открыт фрейм модуля или вкладка неактивна (`anim-paused`).
- Внешние ссылки (не модули) — по-прежнему открываются как раньше: свои — в текущей вкладке, чужие — в новой (`target=_blank`, `noopener`).

🌍 Локализация интерфейса (RU/EN)

- Добавлено полноценное переключение языка интерфейса через `data-i18n` / `data-i18n-aria` атрибуты и словарь переводов на JS.
- Язык по умолчанию определяется по системной локали устройства (через `settings get system system_locales`, раньше проверялось только `en-RU`/`ru-*`), с сохранением выбора в `localStorage`.
- В меню появился отдельный селектор языка (`RU`/`EN`), рядом с выбором темы.

🎨 Полностью переработанный интерфейс

- `styles.css` переписан почти с нуля: новые компоненты — `status-chip`, `signal-bars`, `widget-card`, `icon-badge`, `nav-panel`, `section-label`, `eyebrow`, `main-heading`, `module-dot` и др.
- Боковое меню превратилось в отдельную панель (`nav-panel`) с кнопкой явного закрытия (`nav-close`), а не только через повторный клик по гамбургеру.
- Подключены веб-шрифты Google (`Poppins`/`Inter`) вместо системного `Roboto`.
- Добавлен `viewport-fit=cover` для корректной отрисовки на экранах с вырезами/чёлкой.
- Убраны 3 темы (`mutedOcean`, `duskyLavender`, `foggyRiver`), список тем немного сокращён и переработан визуально.

⚙️ Прочее

- В nginx-конфиге модулей теперь раздача `index.html` идёт напрямую через Lua (`content_by_lua_block`) с `Cache-Control: no-store`, чтобы шим `ksu` и токен всегда были свежими, а не кэшировались.
- Добавлен `try_files ... @module_fallback` с определением модуля по `Referer` — подстраховка для относительных путей внутри модульных webroot'ов.
- В `customize.sh` убрана строка `chmod 755 /data/adb/modules` (больше не трогает права на чужую директорию модулей при установке).
